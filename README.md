# Full Stack Contact Form with React, Node.js, Express, MySQL, and Framer Motion

This project is a fully functional full-stack contact form built using **React** for the frontend, **Node.js** and **Express** for the backend, and **MySQL** for the database. The form allows users to submit their contact details, which are stored securely in a MySQL database. The frontend is styled with **Framer Motion** for smooth and professional animations to enhance user experience.

## Key Features:

### Frontend:
- Built with **React.js**, providing a responsive and dynamic user interface.
- **Framer Motion** used for adding smooth animations and transitions to form elements and other UI components.

### Backend:
- Developed with **Node.js** and **Express** to handle form submissions and interact with the MySQL database.
- Implements RESTful API endpoints to receive and store contact form data in MySQL.

### Database:
- Uses **MySQL Workbench** for storing and managing user data securely.
- Data validation and protection mechanisms in place.

### Animations:
- **Framer Motion** for entrance animations, hover effects, and smooth transitions on form inputs and buttons, enhancing the user experience.

## Technologies Used:
- **Frontend:** React.js, Framer Motion
- **Backend:** Node.js, Express
- **Database:** MySQL
- **Other:** MySQL Workbench

## Setup Instructions:

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/divyareddy083/Contact_Form.git

2. Install Dependencies in both frontend and backend directories
    npm install 
3. Set up MySQL database (schema provided in the repository).
4. Run the backend server: (in the server.js file in the backend change the user,password before running the server)
    node server.js (inside the backend directory)
5. Run the frontend server:
    npm start (inside the frontend directory)
6. Access the contact form in your browser and start interacting with it.
